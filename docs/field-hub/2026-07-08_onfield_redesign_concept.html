Heritage Field Instrument

Kein neues System — das dokumentierte endlich gebaut, plus die Signature-Hebel, die aus „korrekt zurückhaltend" ein premium Sport-Operations-Instrument machen. Ruhig im Live-Betrieb, markant an den Rändern. Ein Konzept zum Draufschauen und Weiterentscheiden — nicht der finale Produktionsstand.

Regel
Status = immer Farbe plus Form/Glyph/Text (8 % Rot-Grün-Schwäche). Oxblood taucht in Live-Screens praktisch nie auf — nur auf Brand-Surfaces (Welcome, Login, Kiosk-Welcome, Splash).
02

Typografie — die Zahlen sind der Held

Der schnellste Weg von „MVP" zu „designt": eine strenge Skala, max. 3 Gewichte pro Screen (dein eigenes Spec!) und überdimensionale tabellarische Scoreboard-Zahlen für Readiness, Load, Minuten. Eine Display-Headline (nach Test lizenziert) trägt die Marke.

03

„Squad heute" — die neue Startseite

Warum das abhebt
Scoreboard-Zahlen + Readiness-Dots + Sparklines = Lage auf einen Blick (Best-Practice der ernsten Liga: TeamBuildr/Kitman). „Kein Check-in" ist ein eigener Zustand (nie als grün getarnt). Eine Primäraktion. Row-first statt Karten-Wand.

Readiness Ø
  • Row-first Athletenzeilen (Dot · Name · Position · Sparkline · Chip) statt Karten-Wände.
  • Genau eine Primäraktion pro View; destruktives hinter Overflow.
  • Jede Aktion quittiert — Haptik + Inline-„gespeichert" (heute nur in PlayersView, künftig überall).
  • Live-Screens bleiben ruhig/operativ; Oxblood & Hero nur auf Brand-Surfaces.
06

Was daraus als Nächstes wird

  • Design-Tokens v2 in tokens.css: echte Typo-Skala + Gewicht-Disziplin + Dark/Field-Mode-Tokens.
  • „Squad heute" als erster redesignter Screen (row-first), dann der Session-Cockpit-Loop.
  • P0-Blocker parallel (Kiosk-Schloss, Save-Feedback, Returner im Loop, Roh-Copy raus).
  • Logo/Wortmarke + Display-Font-Test als eigener Branding-Schritt.
  • Alles token- & komponentenweise spezifiziert — damit ein späterer Flutter/RN-Weg sauber bleibt.
